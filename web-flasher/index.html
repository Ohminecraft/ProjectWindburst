Windburst Flasher

Flash the Windburst firmware to an ESP32 board from this page (Chrome or Edge on a computer; Web Serial).

Flight controller: ESP32-S3 (N16R8)

The main target. The app over a USB-UART bridge or the chip's own USB.

Flight controller: ESP32 (classic, 4 MB)

Smaller boards; fewer features fit (see the docs).

STM32 boards are experimental and cannot be flashed from this page (use STM32CubeProgrammer or dfu-util with the .bin of the release). For an STM32 flight controller you fly, prefer a firmware with a long flight history: Betaflight, ArduPilot, INAV or PX4.

Steps

  1. Take the propellers off.
  2. Plug the board in by USB. A board that does not show up: hold BOOT, press RESET, release BOOT (download mode).
  3. Press "Connect and flash", pick the port, confirm. A first install erases the flash (settings and logs included).
  4. Open the configurator: python -m wbclient gui in app/, or the Windows app of the release.

Sources, documents and every release: github.com/Ohminecraft/ProjectWindburst_Re (GPL-3.0).
